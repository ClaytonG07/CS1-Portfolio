# Pi Approximation

## Description
This program asks the user for an error tolerance. Then the program prints an approximation of pi using the infinite sum until that error tolerance is reached
## Skills Practiced:
- Using while loops
- Using floats
- Using user input
- Using long arithmetic (parenthesis, exponents, etc)

## What I Learned
- How to increment inside of a while loop to prevent an infinite loop
- How to create a table using a while loop
- How to use global variables
